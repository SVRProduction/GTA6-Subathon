# המסע – סאבתון GTA 6

עמוד אחד לצופים, בהשראת עמודי "מסע על מפה": גוללים והמפה זזה איתך לאורך המסלול, מהמשימה הראשונה ועד איפה שאנחנו עכשיו.
כל משימה היא סיכה על המפה. מיילסטונים הם סיכות עגולות גדולות עם תמונה. לחיצה על סיכה פותחת פאנל צד עם הריקאפ המלא,
ציטוט, קטע מהלייב והורדה. יש פס פרקים, מד (יום / משימות / מיילסטונים), פס התקדמות, מפת מיקום קטנה,
מצב "סייר חופשי" (גרירה וזום), ו"יומן המסע" – כל העצירות כרשימה.

- `index.html` – האתר לצופים
- `admin.html` – פאנל הניהול (להוסיף/לערוך נקודות תוך כדי לייב, גם מהטלפון)

## הרצה מקומית

```bash
npm install
```

```bash
npm run dev
```

בלי הגדרות נוספות האתר רץ ב**מצב דמו**: נתוני דוגמה, והשינויים באדמין נשמרים רק בדפדפן שלך.

## חיבור Supabase (כדי שהעדכונים יגיעו לכל הצופים)

1. פתח פרויקט חינמי ב‑[supabase.com](https://supabase.com).
2. ב‑**SQL Editor** הדבק את התוכן של `supabase/schema.sql` ולחץ Run.
3. מודים מתחברים **רק עם Kick** (ראו "מודים" למטה). אין משתמשי אימייל.
   כבו הרשמה חופשית: **Authentication → Sign In / Providers → Allow new users to sign up = off**.
4. ב‑**Project Settings → API** העתק את ה‑Project URL ואת ה‑anon public key.
5. ב‑GitHub: **Settings → Secrets and variables → Actions → Variables** הוסף
   `VITE_SUPABASE_URL` ו‑`VITE_SUPABASE_ANON_KEY`.
   (להרצה מקומית: קובץ `.env.local` עם אותם שני משתנים.)

ה‑anon key הוא מפתח ציבורי – ההגנה היא ב‑RLS שבסכמה: כולם קוראים, רק מודים (`public.is_mod()`) כותבים.

## מודים (התחברות עם Kick + רשימה)

- **מי מוד:** הבעלים, ומי שהבעלים הוסיפו לרשימה באדמין ← "מודים" (לפי שם המשתמש ב-Kick, בלי הבדל בין אותיות גדולות לקטנות).
- **בעלים:** `odedsvr` ו-`ZSWolt` (העמודה `settings.owners`), ובעל הערוץ שמוגדר ב-"ערוץ Kick". הבעלים תמיד מודים, ורק הם מוסיפים ומסירים מודים, משנים את הערוץ ואת רשימת הבעלים. את רשימת הבעלים משנים ב-SQL Editor:
  ```sql
  update public.settings set owners = '{odedsvr,zswolt}' where id = 1;
  ```
- **התחברות:** "התחברות עם Kick" באדמין או באתר. אם השם ברשימה, כלי העריכה מופיעים (גם במפה). אם לא – נשארים צופים רגילים.
- **הסרה תופסת מיד:** כל בקשת עריכה נבדקת מול הרשימה במסד, גם אם הטוקן עוד תקף.
- **שם שהתחלף:** בכניסה הראשונה נשמר מזהה ה-Kick של המוד. אם השם עובר לחשבון אחר, הוא לא יקבל הרשאה עד שהבעלים יסירו ויוסיפו אותו מחדש.

הפעלה (אחרי ש-`kick-auth` עובד, ראו "תגובות"):
1. מריצים שוב את `supabase/schema.sql`.
2. מעתיקים את ה-JWT secret: **Project Settings → JWT Keys → Legacy JWT secret** (בפרויקטים ישנים: **API → JWT Secret**).
3. מגדירים ופורסים:
   ```bash
   supabase secrets set SUPABASE_JWT_SECRET=<ה-JWT secret>
   supabase functions deploy kick-mod --no-verify-jwt
   ```
`kick-mod` מקבלת את הכרטיס החתום של Kick, בודקת שהמשתמש בעלים או ברשימה, ומחזירה טוקן Supabase למודים בלבד (תקף 12 שעות, מתחדש לבד).


## לייב, זמן משחק, קליפים וספירות (Kick)

בלי שום הגדרה האתר מציג את כל אלה במצב דמו. כדי שיעבדו באמת:

1. **טבלאות**: מריצים שוב את `supabase/schema.sql` (בטוח להריץ כמה פעמים).
2. **הפונקציה שבודקת את Kick** (צריך Supabase CLI: `npm i -g supabase`):
   ```bash
   supabase login
   supabase link --project-ref <PROJECT_REF>
   supabase secrets set CRON_SECRET=<מחרוזת-אקראית-ארוכה>
   supabase functions deploy kick-sync --no-verify-jwt
   ```
3. **בדיקה שה-Kick עונה מהשרת**: פותחים בדפדפן
   `https://<PROJECT_REF>.supabase.co/functions/v1/kick-sync?action=probe`.
   אמורים לראות `"status": {...}` בלי `error`. אם יש `403` מ-Kick, ממשיכים לסעיף 5 (האפליקציה של Kick היא הגיבוי).
4. **הפעלה כל 2 דקות**: ב-SQL Editor מריצים את `supabase/cron.sql`, אחרי שמחליפים בו את `<PROJECT_REF>` ואת `<CRON_SECRET>`.
5. **פקודות צ'אט** (`!מוות`, `!חתול`, ועם `-` לביטול; רק אתה ומודרטורים):
   - kick.com → Settings → Developer → Create App. בשדה Webhook URL שמים
     `https://<PROJECT_REF>.supabase.co/functions/v1/kick-webhook`.
   - `supabase secrets set KICK_CLIENT_ID=... KICK_CLIENT_SECRET=...`
   - `supabase functions deploy kick-webhook --no-verify-jwt`
   - פעם אחת: `curl -X POST -H "x-cron-secret: <CRON_SECRET>" "https://<PROJECT_REF>.supabase.co/functions/v1/kick-sync?action=subscribe"`

**איך זה עובד:**
- **זמן משחק** נספר רק כשאתה בלייב בקטגוריה שבהגדרות (ברירת מחדל `grand-theft-auto-vi`). הפסקה של יותר מ-6 דקות לא נספרת.
- **תג "משחק עכשיו"** נעלם לבד אם הבדיקה האוטומטית נעצרה. המתג הידני "אני בלייב" באדמין משמש רק כגיבוי.
- **קליפים** מהקטגוריה נמשכים לבד ומופיעים בכפתור "קליפים". כל קליפ משויך לעצירה שהייתה פעילה כשצולם.
- **ספירות**: בכפתורים באדמין (`admin.html#counters` הוא מסך מלא לטלפון), או בפקודות צ'אט. כל ספירה משויכת למשימה הנוכחית.

## Mission Control: חלונות קופצים, מרקרים, סטוריז וסקרים

הכול נפתח כחלון קופץ מעל המפה (בלי לעבור עמוד), עם כתובת משלו לשיתוף:
`#stats` סטטיסטיקות · `#feed` פיד חי · `#clips` קליפים · `#stops` כל העצירות · `#layers` שכבות ומקרא · `#poll` הסקר · `#phone` הטלפון · `#marker-<id>` מרקר · `#guide` מדריך למודים.
`stats.html` הישן מפנה ל-`#stats`.

- **זמן משחק** גדול בצד שמאל. מונה המיתות לא על המסך – הוא בסטטיסטיקות (על המסך נשאר רק ההבזק "מתת").
- **הטלפון** (כפתור באמצע למטה): סטוריז, העלאת סטורי, צ׳אט (תגובות אחרונות) והסקר. כדי להעלות, לעשות לייק או להגיב – התחברות עם Kick.
  **כל סטורי של צופה עובר אישור מוד** (אדמין → "סטוריז לאישור") ונעלם אחרי 48 שעות. הגבלות: אחד לכל 2 דקות, עד 6 ביום, JPEG עד ~1.5MB.
- **מרקרים חופשיים** בכל מקום על המפה, לא קשורים למסלול: מוות, רכב חדש, נשק חדש, נכס, שוד, מרדף, רגע, החלטת הצ׳אט, ומותאם (אימוג׳י). אפשר לצרף תמונה.
  מרקר "מוות" מעלה גם את מונה המיתות (ומחיקה שלו מורידה). צופים יכולים להסתיר סוגים בחלון "שכבות".
- **סקרים לצ׳אט**: מוד פותח סקר (מהמפה עם מיקום, או מהאדמין), הצופים כותבים `!1` / `!2` … בצ׳אט של Kick או מצביעים באתר. קול אחד למשתמש, אפשר לשנות.
  כשהסקר נגמר (בזמן, או "סגירה עכשיו") – אם נבחר מיקום, נוצר שם מרקר **"הצ׳אט החליט: …"**.

### מי מוד?
- **עם Supabase**: מי שמחובר באדמין (אותו דפדפן) רואה במפה את כפתורי "עריכה", "סקר" ו-"?".
- **במצב דמו**: כניסה לאדמין, או `?mod` בכתובת (`?mod=0` מבטל).
בכניסה הראשונה של מוד נפתח מדריך קצר (6 צעדים + צ׳קליסט לפני לייב). אפשר לפתוח אותו שוב עם "?".

### מצב עריכה (במפה)
- **E** או "עריכה": מגש כלים בתחתית. בוחרים כלי ← לוחצים על המפה. "עצירה" מוסיפה עצירה למסלול (ואפשר לסמן "זאת העצירה שאנחנו בה עכשיו").
- **גרירה** של מרקר מזיזה אותו. **לחיצה** על מרקר במצב עריכה פותחת עריכה / מחיקה. בכרטיס של עצירה יש "עריכת העצירה".
- **בטלפון**: לחיצה ארוכה על המפה (במחשב: קליק ימני) פותחת "מה להוסיף כאן?".
- **P** – סקר חדש. **Esc** – ביטול כלי / יציאה.

### אוברליי לשידור (OBS)
1. ב-OBS: **Sources → + → Browser**.
2. URL: `https://svrproduction.github.io/gta6-subathon/overlay.html` · רוחב 1920 · גובה 1080.
3. לא צריך CSS מותאם – הרקע כבר שקוף. מסמנים "Refresh browser when scene becomes active".

פרמטרים: `?pos=bl` (שמאל למטה, ברירת מחדל) / `br` / `tl` / `tr` · `?clock=1` מוסיף את שעון זמן המשחק · `?map=0` בלי מיני-מפה · `?scale=1.2` הגדלה.
האוברליי מופיע רק כשיש סקר פתוח, ומציג את המנצח כ-20 שניות אחרי הסגירה.

### הפעלה ב-Supabase
1. מריצים שוב את `supabase/schema.sql` (מוסיף את הטבלאות `markers`, `stories`, `story_likes`, `polls`, `poll_votes`, את הדלי `stories` ואת הפונקציות `open_poll` / `close_poll`).
2. פורסים את הפונקציה החדשה ומעדכנים את הקיימות:
   ```bash
   supabase functions deploy kick-viewer --no-verify-jwt
   supabase functions deploy kick-webhook --no-verify-jwt
   supabase functions deploy kick-sync --no-verify-jwt
   supabase functions deploy kick-comment --no-verify-jwt
   ```
   `kick-webhook` קולט עכשיו גם הצבעות (כל צופה, לא רק מודים). `kick-sync` סוגר סקרים שהזמן שלהם נגמר.

## תגובות

- **תגובות** על עצירות, קליפים, מרקרים וסטוריז, עם התחברות דרך Kick. אתה והמודים מנהלים אותן באדמין ("תגובות אחרונות"): הסתרה, מחיקה וחסימה.

הפעלת התגובות (אחרי ש-Supabase והאפליקציה של Kick קיימים):
1. מריצים שוב את `supabase/schema.sql`.
2. באפליקציה ב-Kick מוסיפים Redirect URL: `https://<PROJECT_REF>.supabase.co/functions/v1/kick-auth`
3. מגדירים סודות ופורסים:
   ```bash
   supabase secrets set SESSION_SECRET=<מחרוזת-אקראית-ארוכה> ALLOWED_RETURN=https://svrproduction.github.io/
   supabase functions deploy kick-auth --no-verify-jwt
   supabase functions deploy kick-comment --no-verify-jwt
   ```
   (`KICK_CLIENT_ID` / `KICK_CLIENT_SECRET` כבר מוגדרים מהשלב של פקודות הצ'אט.)

**הגנות:**
- **ההתחברות** מתבצעת בשרת: הדפדפן מקבל רק כרטיס חתום (מזהה, שם ותמונה), תקף ל-30 יום.
- **מגבלות על כל תגובה**: אחת לכל 15 שניות, עד 30 בשעה, עד 500 תווים. קישורים מנוטרלים.
- **משתמש חסום** לא יכול להגיב, וכל התגובות שלו מוסתרות.

## המפה

- המפה של האתר היא `public/map.webp`, ומוצגת **בדיוק כמו שהיא**: בלי פילטרים ובלי שכבות מעליה. הרקע מסביב לוקח את צבע השוליים שלה.
- **לבדוק לפני פרסום:** בתמונה הנוכחית יש סימן מים של מי שיצר אותה. כדאי לוודא שמותר להשתמש בה, או להחליף בצילום של המפה מהמשחק.
- להחלפה: אדמין → הגדרות → **העלאת מפה**. כדאי תמונה חדה (2000px ומעלה); מעל 4096px מוקטנת אוטומטית. "חזרה למפה המקורית" מחזיר את `map.webp`.
- בכל נקודה באדמין: **"איפה זה קרה על המפה?"** – לוחצים או גוררים על המפה. נקודה בלי מיקום ממוקמת אוטומטית בהמשך המסלול.
- "כמה קרוב המצלמה": כמה מהמפה רואים בזמן המסע (במסע המפה תמיד ממלאת את רוחב המסך).

## שימוש בזמן לייב

- **+ נקודה חדשה** – שם, תקציר, סוג (משימה / קטע חשוב). נקודה חדשה מסומנת אוטומטית כ"אנחנו כאן".
- **★ מיילסטון** – סיכה עגולה גדולה עם התמונה, סימון בפס ההתקדמות וריקאפ מלא.
- **פרק / ציטוט** – מקבצים את הסיכות בפס הפרקים; הציטוט מופיע בפאנל.
- **קישור לקטע מהלייב** – קליפ/VOD של Kick נפתח בלשונית חדשה; קישור YouTube או קובץ mp4 ישיר מתנגנים בתוך האתר.
- **הורדה** – קישור, או העלאת קובץ (עד 50MB בתוכנית החינמית של Supabase, 1GB בסך הכול; לקבצים גדולים עדיף קישור ל‑Drive וכד׳).
- **📍** – מחזיר את "אנחנו כאן" לנקודה אחרת. **↑ ↓** – שינוי סדר.
- **הגדרות** – כותרת, ערוץ Kick, תחילת הסאבתון, ו"אני בלייב עכשיו" (מציג תג LIVE ונגן).

קישור ישיר לנקודה: `…/#m-5` פותח את הריקאפ של נקודה 5. `…/?2d` מציג רק את יומן המסע.
