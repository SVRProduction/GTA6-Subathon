# המסע – סאבתון GTA 6

עמוד אחד לצופים, בהשראת עמודי "מסע על מפה": גוללים והמפה זזה איתך לאורך המסלול, מהמשימה הראשונה ועד איפה שאנחנו עכשיו.
כל משימה היא סיכה על המפה. מיילסטונים הם סיכות עגולות גדולות עם תמונה. לחיצה על סיכה פותחת פאנל צד עם הריקאפ המלא,
ציטוט, קטע מהלייב והורדה. יש פס פרקים, מד (יום / משימות / מיילסטונים), פס התקדמות, מפת מיקום קטנה,
מצב "סייר חופשי" (גרירה וזום), ו"יומן המסע" – כל העצירות כרשימה.

- `index.html` – האתר לצופים
- `admin.html` – פאנל הניהול (להוסיף/לערוך נקודות תוך כדי לייב, גם מהטלפון)

## הרצה מקומית

```bash
npm install
```

```bash
npm run dev
```

בלי הגדרות נוספות האתר רץ ב**מצב דמו**: נתוני דוגמה, והשינויים באדמין נשמרים רק בדפדפן שלך.

## חיבור Supabase (כדי שהעדכונים יגיעו לכל הצופים)

1. פתח פרויקט חינמי ב‑[supabase.com](https://supabase.com).
2. ב‑**SQL Editor** הדבק את התוכן של `supabase/schema.sql` ולחץ Run.
3. ב‑**Authentication → Users → Add user** צור משתמש (אימייל + סיסמה) לעצמך ולכל מוד. מי שיש לו משתמש יכול לערוך.
   מומלץ לכבות הרשמה חופשית: **Authentication → Sign In / Providers → Allow new users to sign up = off**.
4. ב‑**Project Settings → API** העתק את ה‑Project URL ואת ה‑anon public key.
5. ב‑GitHub: **Settings → Secrets and variables → Actions → Variables** הוסף
   `VITE_SUPABASE_URL` ו‑`VITE_SUPABASE_ANON_KEY`.
   (להרצה מקומית: קובץ `.env.local` עם אותם שני משתנים.)

ה‑anon key הוא מפתח ציבורי – ההגנה היא ב‑RLS שבסכמה: כולם קוראים, רק משתמש מחובר כותב.

## לייב, זמן משחק, קליפים וספירות (Kick)

בלי שום הגדרה האתר מציג את כל אלה במצב דמו. כדי שיעבדו באמת:

1. **טבלאות**: מריצים שוב את `supabase/schema.sql` (בטוח להריץ כמה פעמים).
2. **הפונקציה שבודקת את Kick** (צריך Supabase CLI: `npm i -g supabase`):
   ```bash
   supabase login
   supabase link --project-ref <PROJECT_REF>
   supabase secrets set CRON_SECRET=<מחרוזת-אקראית-ארוכה>
   supabase functions deploy kick-sync --no-verify-jwt
   ```
3. **בדיקה שה-Kick עונה מהשרת**: פותחים בדפדפן
   `https://<PROJECT_REF>.supabase.co/functions/v1/kick-sync?action=probe`.
   אמורים לראות `"status": {...}` בלי `error`. אם יש `403` מ-Kick, ממשיכים לסעיף 5 (האפליקציה של Kick היא הגיבוי).
4. **הפעלה כל 2 דקות**: ב-SQL Editor מריצים את `supabase/cron.sql`, אחרי שמחליפים בו את `<PROJECT_REF>` ואת `<CRON_SECRET>`.
5. **פקודות צ'אט** (`!מוות`, `!חתול`, ועם `-` לביטול; רק אתה ומודרטורים):
   - kick.com → Settings → Developer → Create App. בשדה Webhook URL שמים
     `https://<PROJECT_REF>.supabase.co/functions/v1/kick-webhook`.
   - `supabase secrets set KICK_CLIENT_ID=... KICK_CLIENT_SECRET=...`
   - `supabase functions deploy kick-webhook --no-verify-jwt`
   - פעם אחת: `curl -X POST -H "x-cron-secret: <CRON_SECRET>" "https://<PROJECT_REF>.supabase.co/functions/v1/kick-sync?action=subscribe"`

**איך זה עובד:**
- **זמן משחק** נספר רק כשאתה בלייב בקטגוריה שבהגדרות (ברירת מחדל `grand-theft-auto-vi`). הפסקה של יותר מ-6 דקות לא נספרת.
- **תג "משחק עכשיו"** נעלם לבד אם הבדיקה האוטומטית נעצרה. המתג הידני "אני בלייב" באדמין משמש רק כגיבוי.
- **קליפים** מהקטגוריה נמשכים לבד ומופיעים בכפתור "קליפים". כל קליפ משויך לעצירה שהייתה פעילה כשצולם.
- **ספירות**: בכפתורים באדמין (`admin.html#counters` הוא מסך מלא לטלפון), או בפקודות צ'אט. כל ספירה משויכת למשימה הנוכחית.

## המפה

- המפה של האתר היא `public/map.webp`, ומוצגת **בדיוק כמו שהיא**: בלי פילטרים ובלי שכבות מעליה. הרקע מסביב לוקח את צבע השוליים שלה.
- **לבדוק לפני פרסום:** בתמונה הנוכחית יש סימן מים של מי שיצר אותה. כדאי לוודא שמותר להשתמש בה, או להחליף בצילום של המפה מהמשחק.
- להחלפה: אדמין → הגדרות → **העלאת מפה**. כדאי תמונה חדה (2000px ומעלה); מעל 4096px מוקטנת אוטומטית. "חזרה למפה המקורית" מחזיר את `map.webp`.
- בכל נקודה באדמין: **"איפה זה קרה על המפה?"** – לוחצים או גוררים על המפה. נקודה בלי מיקום ממוקמת אוטומטית בהמשך המסלול.
- "כמה קרוב המצלמה": כמה מהמפה רואים בזמן המסע (במסע המפה תמיד ממלאת את רוחב המסך).

## עיצוב

הכיוון: לילי, שזוף-שמש, מדויק. ה-chrome בגווני הים העמוק של המפה, אקסנט אחד בצבע החול שלה, והצבע העשיר שמור למפה ולתמונות המיילסטונים.
החתימה היא קו ציון בצבע שמנת עם מספרי עצירה. פונטים: IBM Plex Sans Hebrew לממשק ו-Karantina לכותרות.
התנועה לפי עקרונות Apple: תגובה כבר בלחיצה, פאנל שנכנס ויוצא באותו מסלול, גרירה חופשית עם המשך תנועה והתנגדות בקצוות,
וגיליון במובייל שנסגר בגרירה למטה. האתר מכבד הפחתת תנועה, הפחתת שקיפות וניגודיות גבוהה.

העיצוב נעשה לפי [unslop](https://github.com/heydamir/unslop) של Damir Sokolovsky (CC BY 4.0), apple-design ו-web-design-engineer.

## שימוש בזמן לייב

- **+ נקודה חדשה** – שם, תקציר, סוג (משימה / קטע חשוב). נקודה חדשה מסומנת אוטומטית כ"אנחנו כאן".
- **★ מיילסטון** – סיכה עגולה גדולה עם התמונה, סימון בפס ההתקדמות וריקאפ מלא.
- **פרק / ציטוט** – מקבצים את הסיכות בפס הפרקים; הציטוט מופיע בפאנל.
- **קישור לקטע מהלייב** – קליפ/VOD של Kick נפתח בלשונית חדשה; קישור YouTube או קובץ mp4 ישיר מתנגנים בתוך האתר.
- **הורדה** – קישור, או העלאת קובץ (עד 50MB בתוכנית החינמית של Supabase, 1GB בסך הכול; לקבצים גדולים עדיף קישור ל‑Drive וכד׳).
- **📍** – מחזיר את "אנחנו כאן" לנקודה אחרת. **↑ ↓** – שינוי סדר.
- **הגדרות** – כותרת, ערוץ Kick, תחילת הסאבתון, ו"אני בלייב עכשיו" (מציג תג LIVE ונגן).

קישור ישיר לנקודה: `…/#m-5` פותח את הריקאפ של נקודה 5. `…/?2d` מציג רק את יומן המסע.
